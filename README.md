# ZICO — BEYOND THE GAME | 3D Interactive Portfolio

> **"Understanding the systems behind every experience."**

Personal portfolio website for **Truong Dang Vi Thao (ZICO)** — Game Designer Intern / Junior Game Designer / Game QA Tester.

## 🚀 Features

- **3D Hero Scene**: Interactive metallic sculpture built with Three.js and dynamic mouse parallax.
- **Cosmic Space Engine**: Full-site 60 FPS Canvas engine featuring 260+ twinkling stars, multi-colored nebulae, streaking comets, 18 3D tumbling faceted asteroids with directional lighting, and 5 celestial bodies (Saturn with 3D rings, Venus, Mars, Neptune, and Jupiter).
- **Interactive 3D Flip Cards**: Game Design & Game QA roles with click/hover flip mechanics and system breakdowns.
- **Honest Foundational Skill Matrix**: Clean node indicators without inflated percentages.
- **Interactive Lifecycle Pipeline**: 6-step QA & Design validation loop with responsive cards and active state inspection.
- **Live Dispatch & Fitness Telemetry Mockups**: High-fidelity UI windows showcasing backend systems (ASP.NET MVC, Node.js, WebSocket, OpenRouteService).
- **CV Downloads**: Direct PDF downloads for Game Designer & Game QA Tester resumes.

## 🛠️ Tech Stack

- **HTML5 & CSS3**: Custom cyberpunk/space design system, glassmorphism, responsive CSS grid/flexbox.
- **JavaScript (ES6+)**: Custom canvas physics, procedural 3D math & lighting.
- **Libraries**: Three.js (r128), GSAP (3.12.2), ScrollTrigger.
